# Проект ProjectCoursework
## Описание:
Данный проект создан в рамках выполнения курсовой работы по программе обучения "Python-разработчик".
В данном проекте разрабатано приложение для анализа транзакций, которые находятся в Excel-файле. 
Приложение генерирует JSON-данные для веб-страниц, формировать отчеты, а также предоставлять другие сервисы.
## Установка и использование:
1. Откройте PyCharm
2. Клонируйте репозиторий:
```
git clone https://github.com/svetlana-rogova/ProjectCoursework
```
3. Установите зависимости через Poetry:
```
poetri install
```
4. Активируйте виртуальное окружение:
```
poetry shell
```
5. В модуле views.py расписан основной функционал для вывода информации о транзакциях, о курсах валют и акций для 
отображения на веб-страницах. На вход подается дата и файл с транзакциями. Выбрав дату, получаем номер карты, сумму 
расходов по ней, сумму кэшбэка и топ 5 категорий по тратам за текущий месяц. При выводе информации получаем 
приветственное сообщение, которое зависит от настоящего времени, а также курс валют и стоимость акций на данный момент. 
Выбрать акции и валюты можно, изменив данные файла user_settings.json. Чтобы получить данный по API создайте файл .env 
из копии файла .env.example и замените значения переменных реальными данными
6. В модуле utils.py находятся вспомогательные функции для чтения данных из файлов и для формирования приветственного 
сообщения.
7. В модуле services.py находится функция, которая формирует отчет о всех переводах физическим лицам из данных по 
транзакциям в файл file_people.json
8. В модуле reports.py находится функция, которая формирует отчет о тратах по выбранной категории за последние три 
месяца.
## Тестирование:
Все тесты лежат в директории tests/, имена модулей начинаются с test_.
В данной директроии реализованы тесты для каждого модуля из пакета src/.
Для запуска тестирования необходимо установить pytest:
```
poetry add --group dev pytest
```
Запустить тесты можно через команду pytest в терминале:
```
pytest
```
Чтобы проверить покрытие файла тестами нужно установить petest-cov в отдельную группу:
```
poetry add --group dev pytest-cov
```
Проверить покрытие можно через команду:
```
poetry run pytest --cov
```
